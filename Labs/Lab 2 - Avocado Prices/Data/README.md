# Lab 2 data

Keep this Data folder next to the notebook when running the analysis. The rendered HTML can be viewed on its own.

- `avocado-updated-2020.csv`: [Avocado Prices (2020), Kaggle](https://www.kaggle.com/datasets/timmate/avocado-prices-2020).
- `Metro_zhvi_uc_sfrcondo_tier_0.33_0.67_sm_sa_month.csv`: [Zillow Research](https://www.zillow.com/research/data/), monthly metro-level ZHVI for all homes, smoothed and seasonally adjusted. The notebook selects four California metro areas and the 2015–2020 period.
